## 一小段代码

```javascript
function greet(name) {
  return `你好，${name}！`;
}
console.log(greet('Cyrex'));
```

## 一张表格

| 内容 | 需要检查的效果 |
| --- | --- |
| 中文正文 | 换行、标点和段落间距 |
| 代码块 | 缩进、语法高亮和横向滚动 |
| 图片 | 本地文件与网站引用一致 |
| 草稿 | 不会出现在正式网站 |

## 一份清单

- 正文与标题清楚易读。
- 图片可以打开。
- 分类和标签可以访问。
